## Technical Requirements for Capture

- **Resolution:** 1920×1080 minimum. Export at 1080p.
- **Frame rate:** 60fps capture. Trailer deliverable at 30fps or 60fps (Steam supports both).
- **Audio:** In-game sound effects. No voice-over in this version. Background music to be added in post — this script does not specify tracks.
- **UI scaling:** All text must be readable at 1080p. Verify font sizes before capture.
- **Build version:** Capture from the final release build, not from editor. No debug overlays, no console output, no god-mode indicators.

## What NOT to Show

- No mock-ups or concept art
- No AI-generated character illustrations
- No features not present in the shipping build
- No multiplayer (does not exist)
- No real-money purchase UI (does not exist)
- No debug tools or editor interface

## Post-Production Notes

- Music selection is a separate decision. This script covers visual shots only.

- No fancy motion graphics. The trailer should feel grounded — this is a mahjong game with real stakes, not a cinematic spectacle.
- End card template must comply with Steam trailer specs (verify dimensions at upload).
