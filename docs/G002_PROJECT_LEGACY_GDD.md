# G002 — Project Legacy GDD

状态：PARKED / READY（设计存档，可供未来启动；不是可运行产品）。版本0.1，2026-09-11。本周所有主开发资源归 M001，禁止在本周实现 G002 原型、美术或独立基础设施。

## 1. 产品定位
Character-Driven Tactical RPG，角色驱动战术RPG，中西方黑暗幻想世界。学习火焰纹章等类型成熟的角色黏性、阵营、关系、成长、职业和永久死亡语言，但绝不复制受保护角色、剧情、美术、地图、UI、音乐或具体表达。

北极星：玩家记住角色及其选择，角色死亡后仍关心留下来的世界和下一代。长期IP依赖角色、阵营、关系、成长、死亡后果，而非单一技能噱头。

一句话：**The warrior dies. The legacy doesn't.** 战士会死，传承不会。

## 2. 双文明碰撞
东方包括宗门、剑修、刀修、符师、蛊师、御兽、机关师、医师/炼丹、功法、本命兵器、师徒传承。西方包括骑士、教会、贵族、炼金、军团、重甲、圣术。

两个文明的差异必须进入规则、兵种交互、关系和战术决策，不能只有服装换皮，也不能简单把文明分善恶。黑暗幻想是氛围方向，不等于所有人没有选择与希望。具体地名、组织名、历史和角色均待原创设计，不把空缺伪装成已有设定。

### 必须保留的互动方向
- 东方蛊师可寄生重甲骑士。
- 西方圣职可净化蛊。
- 符师改变战场格子/阵法。
- 炼金师可破阵、范围爆破。
- 剑修擅长单体爆发。
- 骑士正面阵型强。

这些是设计例，不代表已平衡或已实现。反制应可读、有代价、有应对，不把某文化流派设计成无脑碾压。**蛊只是多个东方流派之一，禁止升格为唯一核心。**

## 3. 核心 Hook：Legacy / 传承
角色死亡不重置故事：兵器保留并记住主人，功法可继承，徒弟受到影响，仇恨持续，关系和世界后果保留，蛊/灵兽/遗物可转移或变异。

Legacy 不是“死一个换一张同数值卡”，应让系统与叙事共同记录此前的人。永久死亡具有不可替代的角色后果，成长投入可部分传承，但不能消除死亡的情感重量。是否提供宽容模式、存档模式、遗物绑定限制、继承比例均未决，未来原型测试后决定。

### Legacy V0 暂定可验证结构
以下为未来实施假设，不是用户已经批准的具体数值或本周工作：
1. 角色、师徒与兵器有稳定ID；死亡形成不可重复触发的生涯事件。
2. 兵器保留前主人的姓名/记录或一条可见记忆。
3. 至少一项功法/经验传给满足条件的继承者，不能复制无限继承。
4. 至少一条关系或仇恨随死亡改变，后续场景可读取。
5. 保存/读取前后保持死亡与传承一致；遗物既不会丢失也不会重复。

验收不是“写了死亡台词”，而是死亡前后机械状态、关系状态与下一场体验都发生可解释改变。

## 4. 角色、阵营、职业与关系
未来正式IP强调每个角色的欲望、缺陷、立场、背景、关系、成长弧与职业打法；具体名单尚未确定。两阵营不能只按东方/西方肤浅二分，最终价值观与政治冲突待需求研究。

可预留的角色数据：ID、名字、阵营/出身、职业、成长、功法、兵器、师徒、关系、存活状态、事件记录、传承关联。该数据建议是未来实现假设。人物、美术和具体剧情全部原创，不能从参考游戏抽取资源。

## 5. 未来 Prototype Scope
固定边界：6个正式角色、2个阵营、3张战棋地图、Legacy V0。

未来原型必须实际测试：双文明技能反制；至少一次死亡与跨地图传承；角色关系可感知；存档可恢复；玩家能理解永久死亡后果。地图大小、回合制细节、行动经济、职业晋升、敌方AI、操作平台和引擎尚未确认，不为完整感擅自锁定。

“正式角色”是未来原型内容目标，与 M001 首周禁止正式角色图的约束不冲突：本周不生成任何 G002 角色资产。

## 6. 长期循环（暂定）
出征前整备与关系 → 战术战斗/成长 → 生死选择 → 战后世界与传承后果 → 新的阵容与冲突。此循环是由用户 Legacy 方向归纳的设计假设，未来需真人原型测试，不称已验证。

商业模式、发行日期、定价、完整内容量、联网、付费抽卡都未指定；不得替用户默认承诺。

## 7. 激活与验收门
本文件满足“完整存档”，不满足“开发完成”。重新启动需明确资源与日期，且不能侵占 M001 7天冲刺。未来按需求→原型→Builder/Critic→AI Playtest→Evaluator→Human Test→KILL/SCALE推进，商业规模化必须依真实验证。

主要风险：角色死亡挫败与情感价值冲突；传承系统让死亡失去代价；文明互动流于皮肤；蛊挤压其他流派；角色/地图范围失控。验证路径是6角色/2阵营/3地图的最小实验，而非先搭通用战棋超级工厂。
